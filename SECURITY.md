# Security

Report a vulnerability privately through GitHub's "Report a vulnerability" button on this repository (Security tab). Please do not open a public issue for it.

The package reads local JSON and TOML files and prints results. It makes no network calls.

Things worth a private report:

- A case file that makes the linker join legs no identifier or stated rule connects.
- A scenario that makes the simulator report more frozen or returned value than was reported.
